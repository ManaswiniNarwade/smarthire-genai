# Technical Resume & Interview Preparation Guide

## 1. Resume Crafting Fundamentals & ATS Optimization

### The ATS (Applicant Tracking System) Architecture
- ATS parsers strip styling and parse text sequentially. Simple single-column layouts with clear standard section headings (Professional Summary, Technical Skills, Experience, Projects, Education) yield highest parsing accuracy.
- Avoid using complex tables, nested multi-column layouts, graphics, icons, or headers/footers for key data.
- Keyword matching: Match hard skills directly as written in job descriptions (e.g., if the job says "PostgreSQL", don't just say "Databases").

### Transforming Bullet Points with the STAR / Google "X-Y-Z" Formula
Every bullet point should follow: **"Accomplished [X], as measured by [Y], by doing [Z]"**.

#### Weak vs. Strong Examples:
- **Weak:** "Worked on machine learning model for customer data."
- **Strong:** "Developed and deployed a customer churn prediction model in PyTorch and Docker, boosting retention by 14% and generating $220k in annual recurring revenue."
- **Weak:** "Responsible for building the frontend website."
- **Strong:** "Engineered responsive dashboard using Next.js and TypeScript for 30,000 active users, reducing page load latency by 45% through aggressive code-splitting."
- **Weak:** "Helped team with cloud deployment."
- **Strong:** "Architected multi-stage CI/CD pipeline using GitHub Actions and Terraform on AWS, cutting deployment cycle times from 4 hours to 15 minutes."

### High-Impact Action Verbs
- **Leadership / Initiative:** Architected, Spearheaded, Orchestrated, Pioneered, Automated.
- **Performance / Scale:** Scaled, Accelerated, Reduced, Streamlined, Benchmarked, Optimized.
- **Delivery / Engineering:** Engineered, Designed, Implemented, Shipped, Refactored.

## 2. Technical Interview Preparation Framework

### Technical Rounds
1. **Data Structures & Algorithms (DSA):** Master Arrays, Hash Maps, Two Pointers, Trees, Graphs, Dynamic Programming. Focus on time and space complexity tradeoffs (Big-O).
2. **System Design (Mid/Senior):** High-level architecture, database schema, caching, load balancing, message queues, trade-offs (CAP theorem, latency vs consistency).
3. **Domain Machine Learning & GenAI:** Overfitting vs underfitting, regularization, transformer attention mechanism, loss functions, embedding vector metrics, RAG hallucination mitigations.

### Behavioral Rounds (STAR Technique)
- **Situation:** Set the business context and problem scope.
- **Task:** Identify your specific ownership and deliverable.
- **Action:** Explain technical challenges overcome and engineering steps taken.
- **Result:** Conclude with quantified metrics and business impact.
